# JuicyMixer 音频管理器更新日志

本文档记录 JuicyMixer 音频管理器的所有变更。

---

## [3.0.0] - 2026-01-14

### 🎉 阶段 1 完成：核心音频管理系统

#### 新增功能 ✨

##### 1. 核心音频反馈系统
- ✅ **JuicyFeedbackResource** - 音频反馈资源基类
- ✅ **AudioEventResource** - 音频事件资源（兼容旧版）
- ✅ **AudioVariant** - 音频变体系统
- ✅ **JuicyTrack** - 时间线轨道系统
- ✅ **JuicyDriver** - 驱动器系统

##### 2. 随机化与变体系统 🎲
- ✅ **随机容器 (Random Containers)** - 从多个音效中随机选择播放
- ✅ **参数随机化** - 自动随机调整音高和音量
- ✅ **权重控制** - 设置不同变体的触发概率
- ✅ **防重复机制** - 避免连续播放相同音效
- ✅ **AudioVariationManager** - 变体管理器

##### 3. 混音与优先级管理 🎚️
- ✅ **动态鸭霸 (Dynamic Ducking)** - 智能音量调节
- ✅ **虚声部 (Virtual Voices)** - 性能优化机制
- ✅ **播放限额 (Instance Limiting)** - 多层级限制系统
- ✅ **优先级管理** - 智能声音调度
- ✅ **AudioMixingController** - 混音控制器

##### 4. 2D/3D 音频支持 🎵
- ✅ **自动检测** - 智能选择 2D/3D 播放器
- ✅ **独立播放器池** - 性能优化
- ✅ **距离衰减** - 3D 音频衰减支持
- ✅ **AudioPlayer2D/3D** - 专用播放器

##### 5. 架构与管理系统 🏗️
- ✅ **JuicyMixer** - 全局单例接口
- ✅ **JuicyContext** - 运行时上下文管理
- ✅ **对象池系统** - 性能优化
- ✅ **事件系统** - JuicyEvent 架构
- ✅ **中间件系统** - 可扩展架构

##### 6. 可视化编辑器 🎨
- ✅ **Timeline 编辑器** - 可视化时间线编辑
- ✅ **Track 编辑器** - 轨道配置编辑器
- ✅ **Inspector 集成** - 属性检查器扩展
- ✅ **资源创建工具** - 一键创建资源

#### 优化改进 🚀

##### 性能优化
- 🚀 **对象池管理** - 减少 GC 压力
- 🚀 **对象复用** - Context 和 Buffer 复用
- 🚀 **延迟加载** - 按需加载资源
- 🚀 **内存管理** - 自动资源清理

##### 系统优化
- 🚀 **错误处理增强** - 完善的异常处理
- 🚀 **调试工具** - 内置调试系统
- 🚀 **日志系统** - 分级日志输出
- 🚀 **配置系统** - 灵活的配置管理

##### 编辑器体验
- 🚀 **拖拽支持** - 文件拖拽创建资源
- 🚀 **实时预览** - 实时编辑预览
- 🚀 **快捷操作** - 快捷键支持
- 🚀 **主题定制** - 编辑器主题适配

#### API 更新 📖

##### 新增 API
```gdscript
# 全局接口
JuicyMixer.get_singleton()
JuicyMixer.create_context()
JuicyMixer.play_feedback()

# Context API
JuicyContext.play_feedback()
JuicyContext.play_timeline()
JuicyContext.set_group_volume()

# 资源 API
JuicyFeedbackResource.new()
JuicyTimelineResource.create()
```

##### 废弃 API
- ❌ `JuicyAudioEventHandler.play_audio()` (已迁移到新系统)
- ❌ `AudioEventResource.play()` (使用 JuicyMixer)

## 版本说明

### 版本命名规范

- **主版本号** - 重大架构变更或功能重写
- **次版本号** - 新功能或重大改进
- **修订号** - 错误修复或小改动
