## 🐛 调试过程记录

### 主要问题及解决方案

1. **空引用错误**
   - **问题**：测试中`_particle_handler`在某些情况下为null
   - **解决**：添加了`is_instance_valid()`检查

2. **Gradient创建问题**
   - **问题**：`color_ramp.add_point()`在null实例上调用
   - **解决**：先创建Gradient实例，再设置color_ramp

3. **粒子效果不明显**
   - **问题**：粒子太小，在2D场景中难以观察
   - **解决**：增加粒子大小、数量和扩散角度

## 📋 使用指南

### 在游戏中使用音频效果
```gdscript
# 播放音效
var audio_event = JuicyEvent.create_audio_play_event(
    player_node, 
    preload("res://path/to/sound.wav"),
    player_node.position,
    0.8
)
JuicyMixer.add_event(audio_event)
```

### 在游戏中使用粒子效果
```gdscript
# 生成粒子效果
var particle_event = JuicyEvent.create_particle_spawn_event(
    player_node,
    preload("res://path/to/particle.tscn"),
    50,
    player_node.position
)
JuicyMixer.add_event(particle_event)
```
