# Audio Manager Tests

## 测试场景

### test_audio_variant.gd
测试AudioVariant资源类的功能

### test_audio_mixing.gd
测试AudioMixingConfig和混音控制

### test_audio_2d_3d.gd
测试2D/3D自动检测和播放器管理

### test_audio_integration.gd
完整的集成测试

### audio_demo_scene.tscn
交互式演示场景

## 运行测试

在Godot编辑器中打开测试场景并按F5运行。

## 测试音频文件

将测试音频文件放在 `res://sounds/` 目录：
- footstep_1.ogg
- footstep_2.ogg
- footstep_3.ogg
- explosion_1.ogg
- explosion_2.ogg
- dialogue_1.ogg
