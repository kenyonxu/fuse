# Juicy Timeline编辑器使用指南

## 概述

Juicy Timeline编辑器是一个直观的可视化编辑工具，用于创建和管理Timeline资源。它提供了完整的Timeline编辑功能，包括轨道管理、关键帧编辑、实时预览等。

## 安装和启用

1. 确保JuicyMixer插件已正确安装在Godot项目中
2. 在项目设置中启用"JuicyMixer V3"插件
3. 重启Godot编辑器以确保插件正确加载

## 主要功能

### 1. Timeline编辑器面板

Timeline编辑器面板位于编辑器左侧的停靠面板中，提供以下功能：

- **工具栏**：包含播放控制、时间显示、缩放控制等
- **轨道编辑器**：显示和管理所有轨道
- **时间轴画布**：可视化编辑Timeline内容
- **时间标尺**：显示时间刻度和网格

### 2. 轨道管理

支持多种轨道类型：

- **属性轨道**：用于动画属性值的变化
- **反馈轨道**：用于触发反馈效果
- **方法轨道**：用于在特定时间调用方法
- **事件轨道**：用于触发事件

#### 轨道操作

- **添加轨道**：点击工具栏的"+"按钮或使用右键菜单
- **删除轨道**：选择轨道后点击"-"按钮或使用右键菜单
- **重命名轨道**：双击轨道项进行重命名
- **重排序轨道**：拖拽轨道到新位置
- **启用/禁用轨道**：点击轨道旁的可见性按钮
- **静音/取消静音轨道**：点击轨道旁的静音按钮

### 3. 关键帧编辑

#### 属性轨道关键帧

- **添加关键帧**：右键点击属性轨道选择"添加关键帧"
- **移动关键帧**：拖拽关键帧到新时间位置
- **删除关键帧**：选择关键帧后按Delete键
- **编辑关键帧值**：选择关键帧后在属性检查器中编辑

#### 时间吸附

- **启用吸附**：在工具栏中勾选"吸附"选项
- **设置吸附间隔**：在编辑器设置中调整吸附步长
- **智能吸附**：关键帧会自动吸附到最近的时间网格

### 4. 播放控制

- **播放**：点击播放按钮或按空格键
- **暂停**：点击暂停按钮
- **停止**：点击停止按钮或按Esc键
- **时间跳转**：点击时间轴画布跳转到指定时间

### 5. 视图控制

- **缩放**：使用工具栏的缩放滑块或鼠标滚轮
- **平移**：拖拽时间轴画布或使用滚动条
- **适应视图**：双击轨道标题适应所有内容

## 资源创建

### 使用资源创建工具

1. 在编辑器菜单中选择"创建Juicy Timeline"
2. 选择预设模板：
   - **空Timeline**：创建空白Timeline
   - **基础动画**：包含示例属性轨道
   - **复杂序列**：包含多种轨道类型
   - **事件驱动**：主要用于事件触发
   - **粒子效果**：用于粒子系统动画
   - **UI反馈**：用于UI动画效果

3. 设置Timeline参数：
   - **资源名称**：Timeline文件的名称
   - **时长**：Timeline的总时长（秒）
   - **描述**：Timeline的描述信息

4. 点击"创建"按钮保存资源

### 直接创建Timeline

```gdscript
# 创建空Timeline
var timeline = JuicyTimelineResource.new()

# 创建基础动画Timeline
var anim_timeline = JuicyTimelineResourceCreator.create_basic_animation_timeline(2.0)

# 创建复杂序列Timeline
var complex_timeline = JuicyTimelineResourceCreator.create_complex_sequence_timeline(10.0)
```

## 属性检查器

### Timeline属性

在检查器中可以编辑以下Timeline属性：

- **时长**：Timeline的总时长
- **循环模式**：无循环、循环、往返
- **循环次数**：循环次数（0为无限）
- **时间缩放**：播放速度倍率
- **描述**：Timeline的描述信息

### 轨道属性

选择轨道后可以在检查器中编辑：

- **轨道名称**：轨道的显示名称
- **启用状态**：轨道是否启用
- **静音状态**：轨道是否静音

#### 属性轨道特定属性

- **目标节点路径**：要动画的节点路径
- **属性名称**：要动画的属性名称
- **插值模式**：关键帧之间的插值方式

#### 反馈轨道特定属性

- **反馈数据列表**：管理反馈触发器
- **添加反馈数据**：在指定时间触发反馈

#### 方法轨道特定属性

- **目标节点路径**：要调用方法的节点路径
- **方法调用列表**：管理方法调用

#### 事件轨道特定属性

- **事件触发器列表**：管理事件触发器
- **添加事件触发器**：在指定时间触发事件

## 编辑器设置

### 时间轴设置

- **缩放级别**：默认的时间轴缩放
- **启用吸附**：是否启用时间吸附
- **吸附步长**：时间吸附的间隔

### 快捷键

- **空格**：播放/暂停
- **Esc**：停止播放
- **Delete**：删除选中的关键帧或轨道
- **Ctrl+Z**：撤销操作
- **Ctrl+Y**：重做操作
- **Ctrl+S**：保存当前Timeline
- **Ctrl+N**：创建新Timeline

## 最佳实践

### 1. 组织轨道

- 按功能分组轨道（如：位置、旋转、缩放分为不同轨道）
- 使用描述性的轨道名称
- 合理设置轨道的启用状态

### 2. 关键帧管理

- 在关键时间点设置关键帧
- 使用合理的插值模式获得平滑动画
- 避免在同一时间设置过多关键帧

### 3. 性能优化

- 对于长Timeline，使用适当的缩放级别
- 禁用不需要的轨道以提高性能
- 使用吸附功能确保精确的时间对齐

### 4. 协作工作

- 使用描述性的命名约定
- 定期保存Timeline资源
- 使用版本控制管理Timeline文件

## 故障排除

### 常见问题

1. **插件未显示**
   - 检查插件是否正确启用
   - 重启Godot编辑器

2. **Timeline无法播放**
   - 检查Timeline驱动器是否正确配置
   - 确认目标节点路径正确

3. **关键帧无法移动**
   - 检查是否启用了吸附
   - 确认轨道未锁定

4. **属性检查器不显示**
   - 确认选择了Timeline资源
   - 检查插件是否正确加载

### 调试技巧

- 使用编辑器控制台查看错误信息
- 检查Timeline资源的验证结果
- 使用测试场景验证Timeline行为
