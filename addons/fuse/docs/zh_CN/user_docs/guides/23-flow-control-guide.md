# 流程控制指南

Fuse 提供 14 个流程控制指令，用于实现条件分支、循环、游戏暂停和指令嵌套调用等逻辑。

## 指令总览

### 条件分支

| 指令 | 功能 | 关键参数 |
|------|------|----------|
| IfThen | 条件为真时执行子指令（单分支） | 条件、子指令列表 |
| IfElse | 条件为真/假分别执行不同指令（双分支） | 条件、真分支、假分支 |
| RunConditionCheck | 运行条件检查，支持"检查通过时/未通过时"两种模式 | 条件、检查模式、子指令 |

### 循环

| 指令 | 功能 | 关键参数 |
|------|------|----------|
| ForLoop | 计数循环（从起始到结束，指定步长） | 起始值、结束值、步长、循环体 |
| ForEach | 遍历数组/组中的每个元素 | 数组来源、循环体、当前元素变量 |
| WhileLoop | 条件循环（条件为真时持续执行） | 条件、循环体 |
| Count | 计数器（每次触发累加，达到目标值时执行） | 起始值、目标值、步长、达到时执行 |
| BreakLoop | 跳出当前循环 | 无参数 |
| ContinueLoop | 跳过本次循环，进入下一次 | 无参数 |

### 等待

| 指令 | 功能 | 关键参数 |
|------|------|----------|
| Wait | 等待指定秒数 | 等待时间（秒） |
| WaitUntil | 等待直到条件为真（轮询检查） | 条件、检查间隔 |

### 游戏控制

| 指令 | 功能 | 关键参数 |
|------|------|----------|
| PauseGame | 暂停游戏（暂停场景树） | 无参数 |
| ResumeGame | 恢复游戏 | 无参数 |

### 高级调用

| 指令 | 功能 | 关键参数 |
|------|------|----------|
| RunRunner | 触发另一个 ActionRunner 执行 | 目标 ActionRunner 资源 |

## 常见用例

### 1. 敌人 AI 决策

```
OnProcess(每帧)
  → IfThen(距离玩家 < 200)
      → 追逐玩家
  → IfElse(生命值 <= 30%)
      → 真分支: 逃跑
      → 假分支: 攻击
```

### 2. 波次生成系统

```
游戏开始 → Count(波次计数器, 起始=1, 目标=5)
  → 每波: ForLoop(i, 1, 敌人数量)
      → 在随机位置生成敌人
  → Wait(3秒)
  → 下一波
```

### 3. 暂停菜单

```
OnInputKey(ESC)
  → IfThen(游戏未暂停)
      → PauseGame
      → 显示暂停菜单
  → IfThen(游戏已暂停)
      → ResumeGame
      → 隐藏暂停菜单
```

### 4. 遍历所有敌人执行操作

```
ForEach(敌人组)
  → 当前元素存入变量"当前敌人"
  → SetPosition(当前敌人, 随机位置)
  → IfThen(当前敌人.生命值 <= 0)
      → BreakLoop
```

## 注意事项

- IfThen / IfElse 的条件参数需要填写一个 Condition 资源
- ForEach 支持从**变量、节点子节点、节点组**三种方式获取数组
- BreakLoop / ContinueLoop 仅影响**当前最近的一层循环**
- RunRunner 可实现指令的复用，将公共逻辑提取到单独的 ActionRunner
- Wait 是**异步**指令，后续指令会在等待结束后继续执行
- WhileLoop 需要确保循环条件最终会变为 false，否则会导致无限循环
- Count 与 ForLoop 的区别：Count 是基于事件触发的累加器，ForLoop 是一次性执行完毕的循环
