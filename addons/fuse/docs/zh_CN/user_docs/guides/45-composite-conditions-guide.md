# 复合条件指南

Fuse 提供 4 个复合条件，用于通过逻辑组合构建复杂的判断逻辑。复合条件可以嵌套使用，实现任意深度的条件树。

## 条件总览

| 条件 | 逻辑 | 说明 |
|------|------|------|
| CheckAll | AND（且） | 所有子条件都满足时返回 true |
| CheckAny | OR（或） | 任一子条件满足时返回 true |
| CheckNot | NOT（非） | 对子条件取反 |
| CheckComposite | 自定义组合 | 支持自定义逻辑组合方式 |

## 使用方式

复合条件的核心参数是 `conditions` 数组，可以在 Inspector 中添加多个子条件。

### CheckAll - 全部满足

要求**所有**子条件都返回 true，整体才为 true。

```
使用场景: 角色可以攻击
  CheckAll:
    - 条件1: 生命值 > 0      (活着)
    - 条件2: 法力值 >= 10     (有蓝)
    - 条件3: 不在冷却中       (技能可用)
  → 全部满足 → 执行攻击
```

### CheckAny - 任一满足

**任意一个**子条件返回 true，整体即为 true。

```
使用场景: 玩家死亡
  CheckAny:
    - 条件1: 生命值 <= 0
    - 条件2: 掉出屏幕
    - 条件3: 超时
  → 任一满足 → 游戏结束
```

### CheckNot - 逻辑取反

将子条件的结果**取反**。

```
使用场景: 敌人不在视野内
  CheckNot:
    - 条件: 距离玩家 < 视野范围
  → 结果为 true 时表示"敌人不在视野内"
```

### CheckComposite - 自定义组合

支持更灵活的组合方式，可用于构建复杂的条件树。

```
使用场景: 复杂的战斗状态判断
  CheckComposite:
    - 自定义组合逻辑
```

## 嵌套组合

复合条件**支持嵌套**，可以在子条件中再放置复合条件，构建任意复杂的逻辑。

### 示例: 智能寻敌

```
CheckAll:
  - CheckAny:                           # 敌人状态
    - 生命值 > 0                          (存活)
    - 处于复活状态                         (可复活)
  - CheckNot:                            # 不在无敌状态
    - 无敌时间 > 0
  - CheckAny:                           # 距离条件
    - 距离 < 攻击范围
    - CheckNot:                          # 且不在冷却
      - 冷却时间 > 0
```

### 示例: 拾取物品

```
CheckAll:
  - 物品在范围内
  - CheckNot:                           # 背包未满
    - 背包大小 >= 最大容量
  - CheckAny:                           # 物品类型允许
    - 物品类型 == "武器"
    - 物品类型 == "防具"
    - 物品类型 == "消耗品"
```

## 注意事项

- CheckAll 在第一个 false 时立即返回（短路求值），不会评估剩余条件
- CheckAny 在第一个 true 时立即返回（短路求值），不会评估剩余条件
- 嵌套层数过深可能影响可读性，建议将复杂条件拆分为多个层次
- 所有复合条件都支持批量评估（`validate_batch` / `check_batch`），用于多 Trigger 场景的性能优化
