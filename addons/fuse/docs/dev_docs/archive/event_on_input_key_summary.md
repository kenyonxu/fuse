# OnInputKey 事件设计总结

## 项目概述

本项目为 Fuse Visual Programming 系统设计了一个新的 `OnInputKey` 事件类，用于监听用户的键盘输入并触发相应的事件。该设计遵循了项目现有的事件系统架构和最佳实践。

## 核心特性

### 1. 多种按键事件类型支持

- **按下事件（Pressed）**：当按键被按下时触发一次
- **释放事件（Released）**：当按键被释放时触发一次
- **持续按下事件（Held）**：按键持续按下时按配置的间隔重复触发

### 2. 灵活的配置选项

- 支持任意按键的选择和配置
- 可配置的持续按下参数（初始延迟和重复间隔）
- 可选的单次触发模式
- 自定义按键名称显示

### 3. 直观的编辑器界面

- 使用 Godot 内置的 InputEventKey 对话框进行按键选择
- 实时更新资源名称，显示当前配置状态
- 集成到现有的 Inspector 系统中

## 技术架构

### 1. 事件类继承结构

```
BaseEvent (抽象基类)
    └── OnInputKey (具体实现)
```

### 2. 生命周期管理

遵循标准的事件生命周期：
1. **初始化阶段**：设置输入处理和信号连接
2. **运行阶段**：监听按键事件并触发相应的处理
3. **清理阶段**：断开连接并释放资源

### 3. 输入处理机制

- 使用 `_input()` 和 `_unhandled_key_input()` 双重输入处理
- 早期事件过滤，提高性能
- 状态管理，避免重复触发

## 文件结构

```
addons/fuse/

    ├── input_key_selector.gd           # 属性编辑器
    └── input_key_dialog.gd            # 按键选择对话框
```

## 使用场景

### 1. 游戏控制
- 角色移动（WASD 键）
- 跳跃动作（空格键）
- 交互操作（E 键）

### 2. UI 控制
- 菜单导航（方向键）
- 确认/取消（Enter/Escape）
- 快捷键（Ctrl+S 保存等）

### 3. 调试和开发
- 测试模式切换（F1 键）
- 调试信息显示（F3 键）
- 场景重置（R 键）

## 性能优化

1. **输入过滤**：在输入处理函数中尽早过滤不相关事件
2. **定时器管理**：合理配置持续按下事件的触发间隔
3. **资源清理**：确保在不需要时正确释放资源
4. **状态缓存**：避免重复计算和状态检查

## 错误处理

1. **参数验证**：在 `validate()` 方法中验证所有配置参数
2. **运行时检查**：在初始化和运行时检查关键条件
3. **统一错误处理**：使用 `FuseError` 系统进行错误管理
4. **详细日志**：提供分级日志记录，便于调试

## 扩展可能性

1. **多键组合**：支持同时按下多个按键的组合事件
2. **修饰键支持**：支持 Ctrl、Alt、Shift 等修饰键
3. **鼠标事件**：扩展支持鼠标按键和滚轮事件
4. **手柄支持**：扩展支持游戏手柄按键事件
5. **输入映射集成**：与 Godot 的输入映射系统集成
