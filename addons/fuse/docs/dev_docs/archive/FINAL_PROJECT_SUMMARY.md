## 📋 维护指南

### 新建文档时

1. **选择目录**:
   - 面向用户 → `user_docs/`
   - 技术文档 → `system_docs/`
   - 开发相关 → `dev_docs/`
   - 功能提案 → `proposals/`

2. **使用命名规范**:
   - 小写字母 + 下划线
   - 描述性名称
   - 类型后缀（如 _analysis, _design, _guide）

3. **更新索引**:
   - 在对应目录的 README 中添加链接
   - 确保分类准确
   - 添加简短描述

### 定期维护

**频率**: 每季度一次

**检查项**:
- [ ] 文档分类准确性
- [ ] README 链接有效性
- [ ] 过时文档清理或归档
- [ ] 命名规范遵守
- [ ] 新文档添加到索引

### 文档生命周期

1. **创建**: 放在合适的分类目录
2. **更新**: 定期检查和更新内容
3. **归档**: 功能完成后移到 `dev_docs/archive/`
4. **删除**: 仅在无价值时删除（需谨慎）
