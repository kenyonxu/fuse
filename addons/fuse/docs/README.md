# Fuse 文档中心 / Fuse Documentation

Fuse 是一个 Godot 4.7 可视化编程插件：Event / Instruction / Condition 三类砖块在 Inspector 里搭逻辑，AI 可生成 preset，调稳的系统可"毕业"为脱离插件的工程代码。
