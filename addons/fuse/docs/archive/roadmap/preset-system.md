## 核心目标

让用户将 ActionRunner 中的指令序列保存为可复用模板（Logic Template），应用到不同场景时自动适配节点引用。

## 待解决问题

1. **NodePath 重映射策略** — 模板中 `target_node = NodePath("..")` 应用到新场景时如何自动匹配？候选方案：节点名模糊匹配 / 类型匹配 / 手动映射表 / 相对路径保持
2. **自定义编辑器设计** — 模板浏览面板、拖拽应用、预览功能需要哪些 UI 组件？
3. **模板存储格式** — `.tres` 还是自定义格式？需包含哪些元数据（分类、描述、图标、参数签名）？
4. **V1 vs V2 边界** — V1 只做单场景保存/加载？还是直接上跨场景参数映射？
5. **与 Snippet 系统边界** — 预设 = 完整 ActionRunner，Snippet = 部分指令片段？用户如何区分使用场景？
6. **Inspector 集成** — 一键导出/导入按钮放在哪里？右键菜单还是 Inspector 顶部工具栏？
