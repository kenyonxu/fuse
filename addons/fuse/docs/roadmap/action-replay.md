# 指令序列录播设计

**创建日期:** 2026-06-17
**状态:** 骨架 — 待填充
**关联:** [Fuse 新特性路线图](20206-03-20-future-features-roadmap.md)

---

## 核心目标

录播指令执行序列，支持逐步回放、状态追踪、变量快照比对。

## 待解决问题

1. **录播数据格式** — 每条指令执行记录包含哪些字段？（时间戳、指令类型、参数、执行结果、变量快照）
2. **存储策略** — 内存环形缓冲区还是磁盘文件？多长指令链需要多大空间？
3. **回放控制** — 播放/暂停/步进/快进/倒退，UI 用什么控件？时间轴滑块？
4. **变量快照关联** — 如何与变量监视器的 `get_snapshot()` 对接？每步回放时同步显示变量状态
5. **性能开销** — 录播对运行时帧率的影响？是否需要可选开关？
6. **导出与分享** — 录播文件是否可导出为独立文件？用于 bug 报告或教学演示
