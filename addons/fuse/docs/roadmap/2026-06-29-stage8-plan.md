## 2. 任务 8a — NodePath 重映射

### 2.1 NodePath 提取（8a-1）

复用 InstructionAnalyzer._extract_nodepaths（Stage 6.5）。从预设的指令树提取所有 NodePath 引用：

```gdscript
# 新建：addons/fuse/editor/serialization/nodepath_resolver.gd
class_name NodePathResolver
extends RefCounted

## 从预设提取所有 NodePath 引用（去重）
static func extract_nodepaths(instructions: Array) -> Array[String]:
    var found: Array[String] = []
    var report := {"nodes": []}
    _scan_instructions(instructions, report)
    for np_str in report["nodes"]:
        if np_str not in found:
            found.append(np_str)
    return found

static func _scan_instructions(instructions: Array, report: Dictionary) -> void:
    for inst in instructions:
        if inst == null: continue
        InstructionAnalyzer._extract_nodepaths(inst, report)
        # 递归嵌套
        for sub_key in ["instructions", "else_instructions", "loop_instructions"]:
            if sub_key in inst and inst.get(sub_key) is Array:
                _scan_instructions(inst.get(sub_key), report)
        # condition
        if "condition" in inst:
            var cond = inst.get("condition")
            if cond: InstructionAnalyzer._extract_nodepaths(cond, report)
```

### 2.2 自动匹配（8a-2）

```gdscript
## 生成 NodePath 映射建议
static func resolve_mapping(
    old_nodepaths: Array[String],
    target_trigger: Node
) -> Dictionary:  # {old_str: {"new": NodePath, "matched": bool, "suggestions": Array}}
    var mapping := {}
    var target_parent := target_trigger.get_parent()

    for old_np_str in old_nodepaths:
        var old_np := NodePath(old_np_str)
        var result := {"matched": false, "new": NodePath(""), "suggestions": []}

        # 策略 1: 相对路径结构匹配
        var resolved := _match_relative(old_np, target_trigger)
        if resolved != NodePath(""):
            result.matched = true
            result.new = resolved
        # 策略 2: 全局同名匹配
        elif old_np.get_name_count() > 0:
            var node_name := old_np.get_concatenated_names()  # 最后一段名
            var found := _find_node_by_name(target_trigger.get_tree().current_scene, node_name)
            if found:
                result.matched = true
                result.new = target_trigger.get_path_to(found)

        # 无匹配 → 收集建议（场景所有节点供手动选）
        if not result.matched:
            result.suggestions = _collect_node_suggestions(target_trigger)

        mapping[old_np_str] = result
    return mapping
```

### 2.3 导入 UI（8a-3）

扩展现有导入流程（PresetImportDialog 或 Inspector 导入按钮回调）：

```gdscript
## 导入预设时，先解析 NodePath → 显示映射对话框 → 用户确认 → deserialize
func _import_preset_with_mapping(preset: FusePreset, target_node: Node) -> void:
    # 1. 提取 NodePath
    var nodepaths := NodePathResolver.extract_nodepaths(preset.instructions)
    if nodepaths.is_empty():
        # 无 NodePath，直接导入
        FusePresetDeserializer.deserialize(preset, {})
        return

    # 2. 自动匹配
    var mapping := NodePathResolver.resolve_mapping(nodepaths, target_node)

    # 3. 显示映射对话框
    var dialog := NodePathMappingDialog.new(mapping, target_node)
    dialog.confirmed.connect(func():
        var final_mapping := dialog.get_final_mapping()
        FusePresetDeserializer.deserialize(preset, final_mapping)
    )
    EditorInterface.get_base_control().add_child(dialog)
    dialog.popup_centered()
```

**NodePathMappingDialog**（新建，~100 行）：
- 每行：旧路径 Label → 新路径（✓ 自动 / ⚠ OptionButton 手动选）
- 底部：确认/取消
- 确认 → get_final_mapping() 返回 `{old_str: NodePath(new)}`

## 3. 任务 8b — 逻辑流 GraphEdit

### 3.1 InstructionAnalyzer 树结构增强（8b-0，前置）

**问题：** `instructions_flat`（平铺 + prefix 缩进）丢失 then/else 归属 + 父子关系 + 分支标签，无法正确构建 GraphEdit 分支连线（嵌套 if 尤甚）。

**修法：** `_analyze_instructions` 新增 `instructions_tree` 字段（保留树，不替换 flat）：

```gdscript
# instruction_analyzer.gd — analyze_trigger 初始化加：
report["instructions_tree"] = []

# _analyze_instructions 改为返回 tree（同时维持 flat 兼容）
static func _analyze_instructions(instructions: Array, report: Dictionary, prefix: String, tree_out: Array) -> void:
    for inst in instructions:
        if inst == null: continue
        var display_name = inst.resource_name
        if display_name.is_empty(): display_name = inst.get_class()

        # flat 兼容（现有逻辑不变）
        report.instructions_flat.append({"name": display_name, "prefix": prefix})

        # tree 新增（明确 parent + branch label）
        var node := {
            "name": display_name,
            "inst": inst,  # 原始指令引用（提取节点/变量用）
            "children": {}  # {"then": [...], "else": [...], "loop": [...]}
        }
        tree_out.append(node)

        _extract_nodepaths(inst, report)
        _extract_variables(inst, report)
        if "condition" in inst:
            var cond = inst.get("condition")
            if cond:
                _extract_nodepaths(cond, report)
                _extract_variables(cond, report)

        # 递归嵌套（子树写入 children，branch label 明确）
        for sub_key in _SUB_INSTRUCTIONS:
            if sub_key in inst:
                var branch_label := _sub_key_to_branch(sub_key)
                node.children[branch_label] = []
                _analyze_instructions(inst.get(sub_key), report, prefix + "  ", node.children[branch_label])

static func _sub_key_to_branch(p_key: String) -> String:
    match p_key:
        "instructions": return "then"
        "else_instructions": return "else"
        "loop_instructions": return "loop"
        _: return p_key
```

**数据结构示例：**
```
instructions_tree = [
    {name: "SetVariable", children: {}},
    {name: "If: health > 0", children: {
        "then": [
            {name: "MoveNode", children: {}},
            {name: "If: enemy > 5", children: {
                "then": [{name: "SpawnEnemy", children: {}}],
                "else": [{name: "Wait", children: {}}]
            }}
        ],
        "else": [{name: "GameOver", children: {}}]
    }},
    {name: "PlaySound", children: {}}
]
```

### 3.2 FuseGraphBuilder（8b-1）

**遍历 instructions_tree（明确 parent + branch）构建 GraphEdit nodes/edges。**

数据格式（匹配自建 FuseGraphEdit.set_graph，非 GDSVirtualGraphEdit）：
- **nodes**（Dictionary）：`{node_name: {kind, title, subtitle, pos}}`
- **edges**（Array of Array）：`[from_name, to_name, from_port, to_port]`
- **pos**： FuseGraphEdit 内部布局（网格）

```gdscript
# 新建：addons/fuse/editor/topology/fuse_graph_builder.gd
class_name FuseGraphBuilder
extends RefCounted

var _idx := 0

## 从 instructions_tree 构建 GraphEdit 数据
static func build(report: Dictionary) -> Dictionary:
    var nodes: Dictionary = {}
    var edges: Array = []
    var builder := FuseGraphBuilder.new()

    # Trigger 根节点
    var trigger_name := "n0"
    nodes[trigger_name] = {
        "kind": "trigger",
        "title": report.get("trigger_name", "?"),
        "subtitle": report.get("event", {}).get("resource_name", "")
    }

    # 遍历 instructions_tree（明确 parent + branch label）
    builder._build_tree(report.get("instructions_tree", []), nodes, edges, trigger_name)

    return {"nodes": nodes, "edges": edges}

func _build_tree(tree: Array, nodes: Dictionary, edges: Array, parent_name: String) -> void:
    for node_info in tree:
        _idx += 1
        var node_name := "n%d" % _idx
        var is_branch := not node_info.get("children", {}).is_empty()

        nodes[node_name] = {
            "kind": "branch" if is_branch else "instruction",
            "title": node_info.get("name", "?"),
            "subtitle": ""
        }
        edges.append([parent_name, node_name, 0, 0])

        # 递归子分支（明确 branch label）
        for branch_label in node_info.get("children", {}):
            var subtree := node_info["children"][branch_label]
            if subtree.size() > 0:
                # branch label 作为第一个子边的标识（通过 from_port 区分 then/else/loop）
                var port := 0  # then=0, else=1, loop=2
                match branch_label:
                    "then": port = 0
                    "else": port = 1
                    "loop": port = 2
                _build_tree(subtree, nodes, edges, node_name)
                # 调整第一条子边 to_port 标记分支
                if edges.size() > 0:
                    edges[-1][3] = port  # to_port = branch label
```

**输出示例（If/Then/Else）：**
```
nodes = {
    "n0": {trigger},
    "n1": {SetVariable},
    "n2": {If: health > 0},        ← branch
    "n3": {MoveNode},              ← then 子
    "n4": {GameOver}               ← else 子
}
edges = [
    ["n0", "n1", 0, 0],  ← trigger → SetVariable
    ["n0", "n2", 0, 0],  ← trigger → If
    ["n2", "n3", 0, 0],  ← If → MoveNode (then, port 0)
    ["n2", "n4", 0, 1],  ← If → GameOver (else, port 1)
]
```

> 嵌套 if 的子指令明确归属各自 parent，不再依赖 prefix 猜测。

### 3.2 FuseGraphEdit + FuseGraphNode（自建，参考 gdscript_ast）

**关键：gdscript_ast 不进 Fuse 发布（.gitignore 本地辅助工具）。Fuse 自建 GraphEdit，不依赖 gdscript_ast。**

参考 [GDSVirtualGraphEdit](../../gdscript_ast/editor/graphs/gds_virtual_graph_edit.gd)（虚拟化）+ [GDSGraphNode](../../gdscript_ast/editor/graphs/gds_graph_node.gd) 的设计，但用 Fuse 自己的 class_name，独立实现。

Fuse 的 Trigger 指令链通常 <30 节点，不需要虚拟化（GDSVirtualGraphEdit 的 SMALL_GRAPH_THRESHOLD=50 以下全量渲染）。

#### FuseGraphEdit（新建，~50 行，简化版无虚拟化）

```gdscript
# addons/fuse/editor/topology/fuse_graph_edit.gd
@tool
class_name FuseGraphEdit
extends GraphEdit

func set_graph(p_nodes: Dictionary, p_edges: Array) -> void:
    for c in get_children():
        if c is GraphNode:
            remove_child(c)
            c.queue_free()
    clear_connections()
    for node_name in p_nodes:
        var info = p_nodes[node_name]
        var gn = FuseGraphNode.new()
        gn.configure(info.kind, info.title, info.subtitle)
        gn.name = info.node_name
        gn.position_offset = info.pos
        add_child(gn)
    call_deferred("_connect_edges", p_edges)

func _connect_edges(p_edges: Array) -> void:
    for edge in p_edges:
        if has_node(edge[0]) and has_node(edge[1]):
            var from_port = edge[2] if edge.size() > 2 else 0
            var to_port = edge[3] if edge.size() > 3 else 0
            connect_node(edge[0], from_port, edge[1], to_port)
```
