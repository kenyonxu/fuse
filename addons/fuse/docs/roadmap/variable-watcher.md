# 运行时变量监视器设计

**创建日期:** 2026-06-17
**状态:** 骨架 — 待填充
**关联:** [Fuse 新特性路线图](20206-03-20-future-features-roadmap.md)

---

## 核心目标

运行时 Dock 面板，实时显示三层作用域（local/scope/global）的变量名、值、类型。

## 待解决问题

1. **三层作用域 UI** — 如何在同一面板区分 local/scope/global？Tab 分页还是折叠树？
2. **实时刷新频率** — 每帧刷新还是定时轮询？性能影响评估
3. **变量修改** — V1 只读还是支持运行时修改值？V2 才加修改功能？
4. **快照接口** — Stage 5 指令录播需要重放变量状态，V1 需预留 `get_snapshot()` API 和序列化格式（JSON/Dictionary）
5. **历史折线图** — V2 的变量值随时间变化曲线，用 Godot 原生绘图还是 Chart 插件？
6. **过滤与搜索** — 变量多时如何快速定位？搜索框 + 按作用域过滤？
