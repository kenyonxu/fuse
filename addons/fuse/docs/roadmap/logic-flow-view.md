# 逻辑流视图设计

**创建日期:** 2026-06-17
**状态:** 骨架 — 待填充
**关联:** [Fuse 新特性路线图](20206-03-20-future-features-roadmap.md)

---

## 核心目标

在编辑器底部新增 Tab，选中 Trigger 节点后渲染其指令执行链路的可视化视图。

## 待解决问题

1. **V1 scope 锁定** — 仅渲染平铺指令列表？不做条件分支可视化、不做编辑/拖拽？验收标准需明确
2. **嵌套逻辑渲染** — if/else/for/while 在视图中如何表示？缩进？连线？折叠节点？
3. **节点与指令的视觉映射** — 每条指令用什么图标/颜色？事件和条件如何区分？
4. **性能** — 长指令链（50+ 条）如何保证渲染流畅？虚拟滚动？
5. **V2 扩展点** — 全场景概览 + 执行高亮 + 事件总线连线，V1 需预留哪些接口？
6. **与预设系统的联动** — 从逻辑流视图拖拽指令到预设模板？
