# 指令序列录播（Action Replay / Playback）

## 状态

提案

## 动机

调试时用户经常需要"回放"一段指令序列的执行过程——"刚才那次跳跃，到底是哪条指令出了问题？"目前只能重新运行游戏并复现操作。现有的 DebugVisualizer 提供事后历史列表查看，缺少逐步回放和状态变化追踪能力。

## 与现有系统的关系

基于现有 `ExecutionTracker` + `DebugVisualizer` 扩展。ExecutionTracker 已有执行步骤记录和变量快照能力，录播在其基础上增加逐步回放、变量状态追踪和错误定位。

| 能力 | 现有 DebugVisualizer | Action Replay |
|------|---------------------|---------------|
| 查看方式 | 列表浏览历史 | 逐步动画式回放 |
| 状态追踪 | 仅最终状态 | 每步执行前后的变量快照 |
| 错误定位 | 手动翻找 | 红色高亮 + 一键跳转 Inspector |
| 性能分析 | 有瓶颈标记但无逐条耗时 | 逐条耗时，超阈值标黄 |

## 核心设计

### 回放面板（扩展 DebugVisualizer 新 Tab）

```
┌─ Action Replay ────────────────────────────────┐
│ [▶ 播放] [⏸ 暂停] [⏮ 上一步] [⏭ 下一步]        │
│ 进度: ═══════░░░░░░░░░░  4/12                  │
│                                                   │
│ ✅ 1. SetVariable  (health = 100)    0.02ms     │
│ ✅ 2. CheckOnFloor  → true           0.01ms     │
│ ✅ 3. ApplyImpulse  (Y: -400)        0.03ms     │
│ 🔴 4. PlaySound    → ERROR!         1.20ms     │  ← 当前帧
│ ⬜ 5. TweenScaleTo  (0.8, 0.1s)      —          │
│ ⬜ 6. SetVariable  (jump_count +1)   —          │
│                                                   │
│ 详情: PlaySound                                    │
│ 错误: AudioStreamPlayer2D not found on "Enemy"  │
│ 变量: { health: 100, jump_count: 1, ... }        │
└───────────────────────────────────────────────────┘
```

### 关键特性

1. **逐步回放** — 上一步/下一步，查看每条指令执行前后的状态
2. **变量快照** — 每步记录当时的变量状态，追踪变量如何变化
3. **错误定位** — 红色高亮出错指令，一键跳转到 Inspector 中的对应指令
4. **性能分析** — 标记耗时异常的指令（超过阈值标黄）

### 录制机制

- 断点命中时，自动录制断点前后的完整执行序列
- 每条指令记录：指令名、参数快照、执行结果、耗时、变量状态快照
- 存储为 `ActionReplay` 资源，可在编辑器中回放

## 前置依赖

- Variable Watcher（实时变量监视能力可复用于回放中的变量快照展示）
