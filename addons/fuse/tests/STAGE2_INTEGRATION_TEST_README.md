## 故障排除

### 问题: 测试失败

**解决方案**:
1. 检查 `addons/fuse/localization/translations.csv` 是否存在
2. 检查 `FuseLocalization` 类是否正确初始化
3. 查看控制台输出的具体错误信息

### 问题: 翻译键缺失

**解决方案**:
1. 运行测试后查看缺失的键列表
2. 在 `translations.csv` 中添加缺失的翻译
3. 重新运行测试

### 问题: 编辑器文件未使用本地化API

**解决方案**:
1. 检查相关编辑器文件
2. 确认使用 `FuseLocalization_class.translate()` 而非硬编码文本
3. 参考已本地化的文件作为示例
