## 🚀 5分钟快速开始

### 安装
1. 将 `addons/juicy/` 文件夹复制到你的 Godot 项目的 `addons/` 目录中
2. 在项目设置中启用 Juicy 插件

### 基本用法
```gdscript
# 在场景中添加 JuicyPlayer 节点
var juicy_player = $JuicyPlayer

# 播放效果链
juicy_player.play()

# 停止效果
juicy_player.stop()

# 暂停/恢复
juicy_player.pause()
juicy_player.resume()
```

### 创建效果链
1. 在 Inspector 中添加 `JuicyPlayer` 节点
2. 在 `effects` 数组中添加效果（如 JuicyPosition2D、JuicyScale2D）
3. 配置每个效果的参数
4. 调用 `play()` 方法触发效果链

## 🎮 核心系统

### Spring 系统
基于物理的 Spring 动画，提供平滑自然的动画效果：
- 支持 Float、Vector2、Vector3、Color 类型
- 自动生命周期管理
- 丰富的信号回调

### 震动系统  
多种震动模式，模拟真实的物理反馈：
- Perlin 噪声、正弦波、随机、冲击震动
- 位置、缩放、旋转、相机震动
- UI 隔离设计，不影响界面元素

### UI效果系统
专为UI控件设计的完整动画系统：
- 颜色、透明度、位置、缩放、旋转动画
- 锚点感知和响应式布局支持
- 批量更新和智能缓存优化

### Timeline系统
基于轨道的时间轴动画系统，提供专业级动画制作能力：
- 多种轨道类型：属性轨道、反馈轨道、方法轨道、事件轨道
- 关键帧系统：支持多种插值模式和自定义曲线
- 参数映射：动态参数绑定和实时更新
- 可视化编辑器：直观的时间轴编辑界面

### 对象池系统
高性能对象管理，显著提升运行时性能：
- 统一池管理架构
- 智能动态扩容
- 自动预热和回收机制
