## 概述

**Property Track**（属性轨道）是 JuicyTimeline 系统中最核心的轨道类型，用于在时间轴上控制节点属性的变化。

### 主要特性

- **属性动画控制**：通过关键帧或曲线控制任意节点属性
- **多种数据类型支持**：支持 `float`、`int`、`Vector2`、`Vector3`、`Color`、`bool` 等类型
- **灵活的插值方式**：提供多种插值类型，包括线性和缓动函数
- **可视化编辑**：在 Timeline 编辑器中直观地编辑关键帧和曲线
- **高级时间控制**：支持时间偏移、缩放和循环模式
- **参数映射**：支持通过外部参数动态控制轨道行为

### 使用场景

Property Track 适用于以下场景：

- **UI 动画**：按钮缩放、透明度变化、颜色渐变等
- **游戏反馈**：受伤时的屏幕震动、攻击时的位置偏移等
- **过渡效果**：场景切换时的淡入淡出、物体移动等
- **数值动画**：血条变化、能量条充能等

## 快速开始

### 第一步：打开 Timeline 编辑器

1. 在编辑器中双击 `JuicyTimelineResource` 资源
2. Timeline 编辑器会自动打开在底部面板

### 第二步：添加 Property Track

1. 在左侧轨道编辑器（Track Editor）中，点击工具栏的 `+` 按钮
2. 在下拉菜单中选择 **"属性轨道"**
3. 新的 Property Track 会自动创建并添加到 Timeline 中

### 第三步：设置目标节点

1. 在轨道编辑器中，点击新创建的 Property Track
2. 在工具栏中会出现一个节点选择器按钮（节点图标）
3. 点击该按钮，在弹出的对话框中选择要控制的目标节点
4. 确认后，目标节点路径会显示在工具栏右侧

### 第四步：选择属性路径

1. 在 Inspector 面板中，找到 `property_path` 属性
2. 下拉菜单会自动显示目标节点的所有可写属性
3. 选择你想要控制的属性（例如：`modulate:a`、`scale`、`position` 等）

### 第五步：添加关键帧

1. 在时间轴画布上，将播放头移动到想要添加关键帧的位置
2. 点击工具栏中的添加关键帧按钮（钥匙图标）
3. 关键帧会自动创建在当前时间位置

### 第六步：播放预览

1. 点击工具栏的播放按钮
2. Timeline 会从播放头位置开始播放
3. 你可以看到属性动画的实时效果

## 创建 Property Track

### 通过轨道编辑器创建

**步骤：**

1. 打开 Timeline 编辑器
2. 在左侧轨道编辑器（Track Editor）的工具栏中，找到轨道类型选择器
3. 选择 **"属性轨道"**
4. 点击 `+` 按钮添加轨道

**默认配置：**

- 轨道名称：`属性轨道_1`、`属性轨道_2` 等
- 目标节点：空（需要手动设置）
- 属性路径：空（需要手动设置）
- 值范围：`Vector2(0.0, 1.0)`
- 混合模式：`OVERRIDE_BASE`（覆盖基础值）
- 相对模式：`true`（叠加偏移量）

### 通过资源创建器创建

**步骤：**

1. 在编辑器菜单中选择 **工具 > 创建Juicy Timeline**
2. 在创建对话框中，点击 **"添加轨道"** 按钮
3. 选择轨道类型为 **"属性轨道"**
4. 配置轨道参数后确认

### 轨道属性说明

创建 Property Track 后，你可以在 Inspector 面板中看到以下属性：

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `track_name` | String | "属性轨道_N" | 轨道名称 |
| `enabled` | bool | true | 轨道是否启用（可见性开关） |
| `muted` | bool | false | 轨道是否静音 |
| `track_color` | Color | Color.WHITE | 轨道在编辑器中的显示颜色 |
| `target` | NodePath | NodePath("") | 目标节点路径 |
| `property_path` | String | "" | 要控制的属性路径 |
| `animation_curve` | Curve | null | 值变化曲线（0-1） |
| `value_range` | Vector2 | (0.0, 1.0) | 值映射范围（最小值，最大值） |
| `relative` | bool | true | 是否是相对值（叠加模式） |
| `blend_mode` | BlendMode | OVERRIDE_BASE | 混合模式 |
| `keyframes` | Array[Resource] | [] | 关键帧数组 |
| `use_absolute_time` | bool | false | 使用绝对时间 |
| `time_offset` | float | 0.0 | 时间偏移 |
| `time_scale` | float | 1.0 | 时间缩放 |
| `wrap_mode` | int | 0 | 循环模式 |
| `use_parameter_mapping` | bool | false | 参数映射开关 |
| `parameter_mappings` | Array | [] | 参数映射数组 |
| `ease_preset` | int | 0 | 缓动预设 |

## 配置目标节点

### 目标节点的重要性

**target** 属性指定了 Property Track 要控制的节点。只有正确设置了目标节点，轨道才能找到并修改属性。

### 设置方法

#### 方法 1：使用节点选择器（推荐）

**步骤：**

1. 在轨道编辑器中选中 Property Track
2. 在工具栏中，点击节点选择器按钮（节点图标）
3. 在弹出的对话框中，浏览场景树并选择目标节点
4. 点击"确定"按钮

**优点：**
- 直观易用
- 自动生成相对路径
- 避免手动输入错误

#### 方法 2：在 Inspector 中手动输入

**步骤：**

1. 在 Inspector 面板中选中 Property Track
2. 找到 `target` 属性
3. 手动输入节点路径（例如：`../Node2D/Sprite2D`）

**路径格式：**

- **相对路径**：`../ParentNode/ChildNode` - 相对于场景根节点
- **绝对路径**：`/root/SceneRoot/Node` - 完整的节点路径

### 目标节点提示

当你选中 Property Track 时，工具栏右侧会显示当前的目标节点：

```
目标: ../Node2D/Sprite2D
```

如果目标节点路径无效或节点不存在，提示会显示警告信息。

### 目标节点验证

Property Track 会自动验证目标节点：

- **节点存在性检查**：确保目标节点在场景中存在
- **属性可写性检查**：只显示可写属性的列表
- **类型兼容性检查**：根据属性类型自动调整值范围

如果目标节点无效，属性下拉菜单会显示：

```
请先选择目标节点
```

## 选择属性路径

### 属性路径格式

Property Track 使用 Godot 的属性路径语法来指定要控制的属性。

**基本格式：**

```
<属性名>
```

**嵌套属性：**

```
<属性名>:<子属性名>:<子子属性名>
```

### 常见属性路径示例

| 属性路径 | 说明 | 数据类型 |
|---------|------|---------|
| `position` | 位置 | Vector2/Vector3 |
| `position:x` | 位置的 X 分量 | float |
| `position:y` | 位置的 Y 分量 | float |
| `scale` | 缩放 | Vector2/Vector3 |
| `modulate` | 颜色调制 | Color |
| `modulate:a` | 颜色调制的透明度分量 | float |
| `rotation` | 旋转（弧度） | float |
| `rotation_degrees` | 旋转（角度） | float |
| `visible` | 可见性 | bool |
| `self_modulate` | 自调制颜色 | Color |
| `size` | 大小 | Vector2/Vector3 |

### 动态属性列表

当你设置了目标节点后，`property_path` 属性会自动生成一个下拉菜单，列出所有可用的属性。

**下拉菜单内容：**

- 节点的所有可写属性
- 自动过滤内部属性（以 `_` 开头的属性）
- 按字母顺序排列

### 属性类型识别

Property Track 会自动识别属性的数据类型，并相应地调整配置：

- **数值类型（float、int）**：显示值范围配置，支持曲线编辑
- **向量类型（Vector2、Vector3）**：支持分量控制
- **颜色类型（Color）**：支持 RGBA 分量控制
- **布尔类型（bool）**：支持状态切换

## 添加和编辑关键帧

### 关键帧概念

关键帧（Keyframe）定义了在特定时间点属性的具体值。Property Track 会在关键帧之间自动插值，生成平滑的动画。

### 添加关键帧

#### 方法 1：使用工具栏按钮

**步骤：**

1. 在时间轴画布上，将播放头移动到想要添加关键帧的位置
2. 点击工具栏中的添加关键帧按钮（钥匙图标）
3. 关键帧会自动创建在当前时间位置

**优点：**
- 快速便捷
- 自动使用当前属性类型
- 自动设置默认值

#### 方法 2：使用右键菜单

**步骤：**

1. 在时间轴画布上，右键点击 Property Track 的任意位置
2. 在右键菜单中选择 **"添加关键帧"**
3. 关键帧会创建在点击位置

#### 方法 3：在 Inspector 中手动添加

**步骤：**

1. 在 Inspector 面板中选中 Property Track
2. 找到 `keyframes` 属性
3. 点击 `[Array]` 右侧的编辑按钮
4. 在数组编辑器中，添加新的关键帧资源

### 编辑关键帧

#### 选择关键帧

1. 在时间轴画布上，点击关键帧（菱形图标）
2. 选中的关键帧会高亮显示（黄色）

#### 修改关键帧时间

1. 选中关键帧后，拖动它到新的时间位置
2. 释放鼠标后，关键帧时间会更新

**拖动模式：**

- **时间拖动模式**：默认模式，只改变时间，不改变值
- **值拖动模式**：只改变值，不改变时间
  - 切换方法：点击工具栏中的拖动模式按钮

#### 修改关键帧值

1. 选中关键帧
2. 在 Inspector 面板中，修改关键帧的 `value` 属性
3. 属性值会根据数据类型显示不同的编辑器：
   - **float/int**：数值输入框
   - **Vector2**：X、Y 输入框
   - **Vector3**：X、Y、Z 输入框
   - **Color**：颜色选择器
   - **bool**：复选框

### 删除关键帧

#### 方法 1：使用键盘快捷键

1. 选中关键帧
2. 按 `Delete` 键

#### 方法 2：使用右键菜单

1. 右键点击关键帧
2. 在右键菜单中选择 **"删除关键帧"**

### 批量操作

#### 批量选择关键帧

1. 点击工具栏中的批量拖动模式按钮（盒子图标）
2. 按住 `Shift` 或 `Ctrl` 键
3. 点击多个关键帧，或者拖动鼠标框选多个关键帧

**批量操作：**

- **批量移动**：拖动选中的关键帧，所有关键帧会同步移动
- **批量删除**：选中多个关键帧后，按 `Delete` 键
- **批量复制**：右键菜单中选择 **"复制选中关键帧"**

## 关键帧插值类型

### 插值类型概述

插值类型决定了关键帧之间的值如何过渡。

### 插值类型列表

| 插值类型 | 说明 | 适用场景 |
|---------|------|---------|
| **Linear（线性）** | 匀速过渡 | 最常用的插值方式，适用于大多数场景 |
| **Ease In（缓入）** | 开始慢，逐渐加速 | 物体开始移动、按钮弹出等 |
| **Ease Out（缓出）** | 开始快，逐渐减速 | 物体停止移动、按钮收回等 |
| **Ease In-Out（缓入缓出）** | 两端慢，中间快 | 完整的动画循环 |
| **Step（阶跃）** | 突然变化 | 状态切换、闪烁效果等 |
| **Custom（自定义）** | 使用自定义切线 | 高级用户需要精确控制曲线形状 |

### 修改插值类型

**步骤：**

1. 选中关键帧
2. 在 Inspector 面板中，找到 `interpolation` 属性
3. 在下拉菜单中选择插值类型

或者在时间轴画布上：

1. 右键点击关键帧
2. 在右键菜单中选择插值类型

### 插值类型可视化

在时间轴画布上，关键帧的图标会根据插值类型显示不同的形状：

- **Linear**：菱形
- **Ease In**：指向右的三角形
- **Ease Out**：指向左的三角形
- **Ease In-Out**：圆形
- **Step**：正方形
- **Custom**：星形

### 自定义切线（高级）

对于 `Custom` 插值类型，你可以设置自定义切线来精确控制曲线形状。

**步骤：**

1. 选中关键帧
2. 在 Inspector 面板中，找到 `in_tangent` 和 `out_tangent` 属性
3. 设置切线值（Vector2）

**切线说明：**

- **in_tangent**：进入切线，控制从上一个关键帧到当前关键帧的曲线
- **out_tangent**：离开切线，控制从当前关键帧到下一个关键帧的曲线

## 值范围配置

### 值范围概念

值范围（`value_range`）定义了 Property Track 输出值的映射范围。

**格式：**

```
Vector2(最小值, 最大值)
```

### 值范围的作用

1. **标准化曲线输出**：动画曲线的输出范围是 0-1，值范围将其映射到实际值
2. **限制关键帧值**：关键帧的值会被限制在值范围内
3. **数据类型适配**：不同的数据类型有不同的默认值范围

### 默认值范围

| 数据类型 | 默认值范围 | 说明 |
|---------|------------|------|
| `float` | (0.0, 1.0) | 浮点数 |
| `int` | (0, 100) | 整数 |
| `Vector2` | (Vector2.ZERO, Vector2.ONE) | 二维向量 |
| `Vector3` | (Vector3.ZERO, Vector3.ONE) | 三维向量 |
| `Color` | (Color.TRANSPARENT, Color.WHITE) | 颜色 |
| `bool` | (false, true) | 布尔值 |

### 修改值范围

**步骤：**

1. 在 Inspector 面板中选中 Property Track
2. 找到 `value_range` 属性
3. 在 X、Y 输入框中分别设置最小值和最大值

**注意事项：**

- 最小值不能大于或等于最大值
- 值范围应该根据实际需求合理设置
- 过大的值范围可能导致动画效果不明显

### 值范围示例

#### 示例 1：透明度动画

```
property_path: modulate:a
value_range: (0.0, 1.0)
```

说明：控制透明度从 0（完全透明）到 1（完全不透明）

#### 示例 2：缩放动画

```
property_path: scale
value_range: (Vector2(0.5, 2.0), Vector2(0.5, 2.0))
```

说明：控制缩放从 0.5 倍到 2.0 倍

#### 示例 3：位置偏移

```
property_path: position:x
value_range: (-100.0, 100.0)
```

说明：控制 X 轴位置偏移，范围从 -100 到 100

## 高级功能

### 时间变换

Property Track 提供了灵活的时间控制选项。

#### 绝对时间模式

**属性：** `use_absolute_time`

- **false（默认）**：时间相对于轨道开始时间
- **true**：时间使用绝对值（从 0 开始）

**使用场景：**
- `false`：大多数动画场景，时间从轨道开始计算
- `true`：需要精确控制时间点的场景

#### 时间偏移

**属性：** `time_offset`

**说明：** 时间偏移量，延迟或提前动画开始时间

**示例：**

```
time_offset: 0.5
```

说明：动画延迟 0.5 秒后开始

#### 时间缩放

**属性：** `time_scale`

**说明：** 时间缩放因子，控制动画播放速度。

**示例：**

```
time_scale: 2.0
```

说明：动画以 2 倍速播放

#### 循环模式

**属性：** `wrap_mode`

**选项：**

- **0 - Clamp**：限制在 0-1 范围内
- **1 - Loop**：循环播放
- **2 - PingPong**：往返播放

**使用场景：**
- `Clamp`：一次性动画
- `Loop`：循环动画（如呼吸效果）
- `PingPong`：往返动画（如摆动效果）

### 混合模式

**属性：** `blend_mode`

**选项：**

- **OVERRIDE_BASE**：覆盖基础值
- **ADDITIVE**：叠加偏移量
- **MULTIPLICATIVE**：乘法混合

#### OVERRIDE_BASE 模式

**说明：** 轨道输出值直接覆盖目标属性的值。

**使用场景：** 完全控制属性值。

#### ADDITIVE 模式

**说明：** 轨道输出值叠加到目标属性的值上。

**使用场景：** 在现有属性值基础上添加偏移，如位置偏移、颜色叠加。

**示例：**

```
property_path: position
blend_mode: ADDITIVE
relative: true
```

说明：在当前位置基础上叠加偏移量。

### 相对模式

**属性：** `relative`

**说明：** 是否使用相对值（叠加模式）。

**使用场景：**
- `true`：叠加模式，适用于偏移、缩放等
- `false`：绝对值模式，适用于完全替换属性值

### 缓动预设

**属性：** `ease_preset`

**选项：**

- **0 - None**：不使用缓动
- **1 - Ease In**：缓入
- **2 - Ease Out**：缓出
- **3 - Ease In-Out**：缓入缓出

**说明：** 预设的缓动函数，应用于动画曲线。

**使用场景：**
- 快速应用常用的缓动效果，无需手动调整曲线

### 参数映射系统

Property Track 支持通过外部参数动态控制轨道行为。

#### 参数映射开关

**属性：** `use_parameter_mapping`

**说明：** 启用或禁用参数映射系统。

#### 参数映射配置

**属性：** `parameter_mappings`

**类型：** `Array[JuicyParameterMapping]`

**每个映射包含：**

- `input_parameter`：输入参数名称（如 "intensity"）
- `mapping_type`：映射类型
- `target_property`：目标属性（如 "time_scale"、"value_range_min"）
- `mapping_curve`：映射曲线

**映射类型：**

- **TRACK_TIME**：映射到时间
- **TRACK_VALUE**：映射到值
- **TRACK_PROPERTY**：映射到轨道属性
- **CUSTOM**：自定义映射函数

**目标属性：**

- `time_scale`：时间缩放
- `time_offset`：时间偏移
- `intensity`：强度（值乘数）
- `offset`：偏移（值加法）
- `scale`：缩放（值乘法）
- `override`：覆盖（值替换）
- `value_range_min`：值范围最小值
- `value_range_max`：值范围最大值

**使用示例：**

```
# 通过 intensity 参数控制动画强度
input_parameter: "intensity"
mapping_type: TRACK_VALUE
target_property: "intensity"
mapping_curve: LinearCurve
```

**运行时控制：**

```gdscript
# 在游戏运行时，通过 Context 设置参数
context.set_override("intensity", 0.5)
```

## 可视化编辑技巧

### 时间轴画布操作

#### 缩放时间轴

**方法 1：使用缩放滑块**

1. 在工具栏中，找到缩放滑块
2. 拖动滑块调整缩放级别（0.1x - 5.0x）

**方法 2：使用鼠标滚轮**

1. 将鼠标悬停在时间轴画布上
2. 滚动滚轮调整缩放级别

#### 滚动时间轴

**方法：**

1. 在时间轴画布底部，找到滚动条
2. 拖动滚动条查看不同时间段

**快捷键：**

- `Ctrl + Z`：撤销
- `Ctrl + Y`：重做
- `Delete`：删除选中的关键帧
- `Space`：播放/暂停

#### 吸附功能

**说明：** 自动对齐关键帧到指定的时间间隔。

**启用/禁用：**

1. 在工具栏中，点击"吸附"复选框

**设置吸附间隔：**

1. 在 Inspector 面板中选中 Timeline 资源
2. 找到 `snap_interval` 属性
3. 设置吸附间隔（例如：0.1 秒）

### 关键帧编辑技巧

#### 拖动模式切换

**时间拖动模式（默认）：**

- 图标：向右的箭头
- 功能：只改变关键帧时间，不改变值
- 使用场景：调整动画时间

**值拖动模式：**

- 图标：向上的箭头
- 功能：只改变关键帧值，不改变时间
- 使用场景：调整动画幅度

**切换方法：**

1. 在工具栏中，点击拖动模式按钮

#### 批量拖动模式

**启用/禁用：**

1. 在工具栏中，点击批量拖动模式按钮（盒子图标）

**批量操作：**

- **框选**：按住 `Shift` 键，拖动鼠标框选多个关键帧
- **批量移动**：拖动选中的关键帧，所有关键帧同步移动
- **批量删除**：选中多个关键帧后，按 `Delete` 键

**注意事项：**

- 批量拖动模式需要明确启用
- 框选需要按住 `Shift` 键
- 批量操作会保持关键帧之间的相对关系

### 曲线编辑

#### 查看曲线

Property Track 会在时间轴画布上绘制关键帧之间的曲线，帮助你直观地了解动画效果。

**曲线颜色：** 青色（Cyan）

#### 曲线类型

- **关键帧少于 2 个**：不绘制曲线
- **使用动画曲线**：如果设置了 `animation_curve`，会使用曲线而不是关键帧
- **使用关键帧插值**：根据关键帧的插值类型绘制曲线

- 位置：轨道编辑器中，每个轨道的右侧

**使用场景：**

- **muted = false**：轨道正常输出

## 常见问题

### Q1：为什么属性下拉菜单显示"请先选择目标节点"？

**A：** 这表示 Property Track 的 `target` 属性为空或无效。

**解决方法：**

1. 在轨道编辑器中，选中 Property Track
2. 点击工具栏中的节点选择器按钮
3. 在弹出的对话框中选择目标节点

### Q2：为什么关键帧无法拖动？

**A：** 可能的原因：

1. 没有选中关键帧
2. 拖动模式设置不正确
3. 时间轴被锁定

**解决方法：**

1. 点击关键帧，确保它被高亮显示
2. 检查拖动模式按钮的状态
3. 确认时间轴没有被其他操作锁定

### Q3：为什么动画效果不正确？

**A：** 常见原因：

1. 值范围设置不合理
2. 插值类型选择不当
3. 相对模式和绝对模式混淆
4. 混合模式设置错误

**解决方法：**

1. 检查 `value_range` 是否符合预期
2. 尝试不同的插值类型
3. 检查 `relative` 和 `blend_mode` 设置
4. 在状态栏查看当前值（播放时会显示）

### Q4：如何创建循环动画？

**A：** 使用循环模式和关键帧配合。

**步骤：**

1. 设置 `wrap_mode = 1`（Loop）
2. 在时间 0.0 和 1.0 处添加关键帧
3. 设置相同的值

**示例：**

```
# 呼吸效果
wrap_mode: 1
keyframes:
  - time: 0.0, value: 1.0
  - time: 1.0, value: 1.0
```

### Q5：如何控制多个属性？

**A：** 为每个属性创建一个 Property Track。

**示例：**

```
# 同时控制位置和缩放
轨道 1: property_path = position, value_range = (Vector2.ZERO, Vector2(100, 100))
轨道 2: property_path = scale, value_range = (Vector2(0.5, 0.5), Vector2(2.0, 2.0))
```

**注意事项：**

- 每个轨道独立控制一个属性
- 确保所有轨道的目标节点相同
- 可以使用 `blend_mode` 控制属性之间的混合方式

### Q6：如何预览动画效果？

**A：** 使用 Timeline 编辑器的播放功能。

**步骤：**

1. 在工具栏中，点击播放按钮
2. Timeline 会从播放头位置开始播放
3. 你可以在游戏场景中看到实时效果

**控制：**

- **暂停**：点击暂停按钮
- **停止**：点击停止按钮（播放头回到 0）
- **跳转**：点击时间标尺或拖动播放头

### Q7：如何导出动画到 Godot AnimationPlayer？

**A：** Property Track 使用的是 JuicyTimeline 系统，与 Godot 原生的 AnimationPlayer 系统独立。

**说明：**

- Property Track 是 JuicyMixer V3 的核心组件
- 它提供了比 AnimationPlayer 更灵活的非线性编辑能力
- 如果需要导出到 AnimationPlayer，需要手动转换

### Q8：为什么节点选择器对话框中看不到某些节点？

**A：** 可能的原因：

1. 节点不在编辑的场景中
2. 节点被隐藏或禁用
3. 节点树过深

**解决方法：**

1. 确保你正在编辑正确的场景
2. 检查节点是否在场景树中可见
3. 使用相对路径而不是绝对路径

### Q9：如何调试 Property Track？

**A：** 使用状态栏和日志。

**方法 1：查看状态栏**

- 播放时，状态栏会显示当前值
- 格式：`当前值: <值>`

**方法 2：查看编辑器输出**

- Timeline 编辑器会在编辑器输出中显示操作日志
- 查找包含 "JuicyPropertyTrack" 的日志

**方法 3：使用断点**

- 在关键帧相关代码中设置断点
- 调试关键帧插值逻辑

### Q10：如何优化 Property Track 性能？

**A：** 以下优化建议：

1. **减少关键帧数量**：只在必要的位置添加关键帧
2. **使用曲线代替关键帧**：简单的动画可以用曲线实现
3. **禁用不必要的轨道**：使用 `enabled` 属性
4. **合理设置值范围**：避免过大或过小的值范围
5. **使用缓动预设**：避免复杂的自定义切线

Property Track 是 JuicyTimeline 系统中最强大的轨道类型，它提供了：

✅ **灵活的属性控制**：支持所有数据类型

✅ **丰富的插值选项**：多种插值类型满足不同需求
✅ **高级时间控制**：时间偏移、缩放、循环模式
✅ **参数映射系统**：支持动态参数控制
✅ **批量操作支持**：提高编辑效率

通过掌握 Property Track 的使用技巧，你可以创建出流畅、丰富的游戏反馈效果。
