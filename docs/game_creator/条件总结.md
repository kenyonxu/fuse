# GameCreator VisualScripting - 条件系统总结

## 目录概述

`Assets/Plugins/GameCreator/Packages/Core/Editor/VisualScripting/Conditions` 目录包含了GameCreator视觉脚本系统中条件(Conditions)相关的编辑器实现。条件是用于判断特定状态或属性是否满足特定要求的逻辑组件，通常用于控制脚本流程中的分支决策。

## 目录结构

### 1. Drawers/ - 绘制器组件

- **ConditionDrawer.cs**
  - 作用：为Condition类提供Unity编辑器中的自定义属性绘制器
  - 功能：在Inspector面板中显示条件的属性和子属性
  - 特点：使用SerializationUtils创建子属性的可视化表示

- **BranchDrawer.cs**
  - 作用：为条件分支提供自定义绘制器
  - 功能：处理条件分支的可视化表示

- **ConditionListDrawer.cs**
  - 作用：为条件列表提供自定义绘制器
  - 功能：在编辑器中显示和管理多个条件的集合

- **BranchListDrawer.cs**
  - 作用：为分支列表提供自定义绘制器
  - 功能：处理多个条件分支的可视化管理

### 2. Selectors/ - 选择器组件

- **TypeSelectorCondition.cs**
  - 作用：提供条件类型的选择器界面
  - 功能：允许用户从可用条件类型中选择特定类型
  - 继承：TypeSelectorListFancy，提供花哨的列表选择界面

- **TypeSelectorElementCondition.cs**
  - 作用：提供元素条件类型的选择器
  - 功能：专门用于选择与游戏对象元素相关的条件类型

### 3. StyleSheets/ - 样式表文件

- **Condition-Head.uss**
  - 作用：定义条件头部区域的UI样式
  - 内容：包含条件标题、图标等元素的样式定义

- **Condition-Body.uss**
  - 作用：定义条件主体区域的UI样式
  - 内容：包含条件参数、设置等元素的样式定义

- **Condition-List.uss**
  - 作用：定义条件列表的UI样式
  - 内容：包含多个条件排列、间距等样式

- **Branch-Head.uss / Branch-Body.uss / Branch-List.uss**
  - 作用：分别定义条件分支头部、主体和列表的UI样式
  - 内容：提供分支结构的视觉样式支持

### 4. Tools/ - 工具组件

- **ConditionItemTool.cs**
  - 作用：处理单个条件项的工具类
  - 功能：提供条件的编辑、删除、状态切换等操作
  - 特点：包含条件符号切换按钮(开/关状态)，使用绿色/红色图标表示

- **ConditionListTool.cs**
  - 作用：处理条件列表的工具类
  - 功能：管理整个条件列表的操作，如添加、删除、重排序等

- **BranchItemTool.cs**
  - 作用：处理单个分支项的工具类
  - 功能：提供条件分支的编辑和管理功能

- **BranchListTool.cs**
  - 作用：处理分支列表的工具类
  - 功能：管理多个条件分支的操作和交互

## 系统功能分析

### 条件系统的核心功能

1. **条件表示与编辑**
   - 提供可视化的条件编辑界面
   - 支持多种条件类型的选择和配置
   - 允许条件组合和嵌套

2. **条件状态管理**
   - 支持条件的启用/禁用状态切换
   - 提供直观的视觉反馈(绿色/红色图标)
   - 允许条件符号(正/负)的切换

3. **UI样式与交互**
   - 提供专门的UI样式表确保视觉一致性
   - 支持拖拽、重排等交互操作
   - 提供清晰的条件层次结构显示

### 条件系统的工作流程

1. **创建条件** - 通过TypeSelectorCondition选择条件类型
2. **配置条件** - 使用ConditionDrawer编辑条件参数
3. **管理条件** - 通过ConditionItemTool和ConditionListTool管理条件集合
4. **视觉呈现** - 使用StyleSheets提供一致的UI外观

## 技术特点

1. **模块化设计** - 将功能分离到不同的组件中，便于维护和扩展
2. **UI工具集成** - 深度集成Unity的UI系统，提供流畅的编辑体验
3. **多态支持** - 支持多种条件类型的统一管理和显示
4. **样式分离** - 将UI样式与逻辑分离，便于主题定制

条件系统是GameCreator视觉脚本中实现逻辑判断和流程控制的核心组件，为开发者提供了强大而灵活的条件配置能力。
