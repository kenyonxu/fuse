# 乐器演奏手法与表现力指南

本指南为创作 Agent（Composer、Harmonist、Rhythmist）和表现力 Agent（Orchestrator）提供乐器演奏特性的参考，帮助避免不切实际的写法，并为 MIDI 表现力注入提供依据。所有原则均为推荐性指导，特殊效果可酌情突破。

## 弦乐组（小提琴、中提琴、大提琴、低音提琴）

| Do | Don't | 原因与示例 |
|----|-------|------------|
| 多用连音线（slur）表达乐句，标注 `!slur!` 或使用括号 `( )` 括起音符组 | 避免连续 8 分音符同音换弓（除非需要顿弓效果） | 同音反复无连线会产生“锯木”感。**Do示例：** `(C4 D4 E4 F4)` 表示一弓演奏四音。 |
| 长音（≥2 拍）添加颤音标记 `!tr!` 或配合 Orchestrator 注入 CC1 颤音 | 长音平直无变化 | 弦乐长音自然带有颤音，MIDI 平直显得机械。 |
| 高把位（高音区）可适当加强力度 | 长时间停留在极高音区（超过两个乐句） | 极高音区紧张感强，容易造成听觉疲劳。 |
| 拨奏（pizzicato）用 `+pizz+` 标记，并通常使用短音符（8 分或 16 分） | 在快速经过句中大量使用拨奏（实际演奏困难） | 拨奏需手指拨弦，过快段落难以清晰演奏。 |
| 双音与和弦尽量开放排列（避免密集小音程） | 连续使用双音跳进超过六度 | 双音跳进需换把，难度高且易失准。 |

**ABC 与 MIDI 配合：**
- 连音线 `( )` 会提示 `abc2midi` 将内部音符的 `note_on` 时间重叠（legato）。
- 颤音可通过 Orchestrator 在 `expression_plan.json` 中为对应音符时间点添加周期性 CC1 变化。

## 木管组（长笛、双簧管、单簧管、巴松等）

| Do | Don't | 原因与示例 |
|----|-------|------------|
| 利用音区特性：低音区温暖，中音区明亮，高音区尖锐 | 给长笛写持续极低音（如中央 C 以下） | 长笛低音区气声重、音量弱，持续使用缺乏穿透力。 |
| 快速音阶适合吐音（staccato），标注 `!staccato!` | 长乐句全用吐音（失去连贯性） | 吐音颗粒感强，但过多会破坏乐句线条。 |
| 装饰音（`!trill!` 或 `{g}f` 等）适合表现轻盈、华丽 | 在极高音区写密集装饰音（如连续 32 分音符颤音） | 高音区指法复杂，装饰音难以清晰演奏。 |
| 乐句间留出换气时间（自然休止或长音尾） | 音符密集无停顿超过 8 小节 | 木管演奏者需要换气，无休止符会导致乐句无法完成。 |
| 单簧管中低音区（记谱 C4–C5）适合抒情旋律 | 单簧管高音区（>C6）连续大跳 | 高音区音准敏感，大跳易出现音准偏差。 |

**ABC 与 MIDI 配合：**
- 断奏 `!staccato!` 会使 `abc2midi` 缩短音符实际长度，Orchestrator 可进一步调整 CC11 做“音头强调”。
- 换气点可在 `expression_plan.json` 中轻微降低 CC11 并快速恢复，模拟呼吸感。

## 铜管组（小号、圆号、长号、大号等）

| Do | Don't | 原因与示例 |
|----|-------|------------|
| 强音（`!f!`）可配合滑音（pitch bend）作为音头 | 连续大跳（超过八度）在快速段落中难演奏 | 铜管演奏大跳需改变口型与气息，连续大跳容易破音。 |
| 弱音器（`+con sordino+`）适合特殊色彩（如爵士、神秘场景） | 长时间高音强奏（超过 4 小节） | 对演奏者嘴唇负担极大，且听感压迫。 |
| 休止符给足换气时间（至少 1 拍） | 音符密集无停顿 | 铜管需大量气息，连续演奏易疲劳。 |
| 圆号可用阻塞音（`+stopped+`）制造金属质感 | 圆号高音区（>G5）长时间持续 | 高音区控制难度大，容易走音。 |

**ABC 与 MIDI 配合：**
- 滑音效果由 Orchestrator 在 `expression_plan.json` 中为音头附近添加 pitch bend 曲线。
- 强音可配合 CC7（通道音量）短时提升，模拟气息冲击。

## 打击乐与鼓组（MIDI 通道 10）

| Do | Don't | 原因与示例 |
|----|-------|------------|
| 滚奏（`!roll!`）用长时值音符 + 标注 | 用 32 分音符连续书写滚奏（谱面冗余） | 滚奏只需标记 `!roll!`，实际演奏由演奏者决定密度。 |
| 吊镲（`a`）用 `!>!` 强调重音 | 开镲（`d`）在每拍正拍使用（会掩蔽其他乐器） | 开镲高频多，频繁使用破坏律动。 |
| 军鼓边击（`D,` + `!x!`）增加节奏层次 | 军鼓和底鼓完全同步（失去 groove） | 同步会削弱节奏层次感，适当错开更生动。 |
| 底鼓（`B,,`）和军鼓（`D,`）形成交替律动 | 连续 4 小节相同鼓 pattern 不变化 | 段落变化需要鼓节奏调整来支持。 |

**固定 GM 映射表（与 ABC 规范一致）：**
| 音色 | ABC 音高 | GM Note |
|------|---------|---------|
| 低音鼓 | `B,,` | 36 |
| 军鼓 | `D,` | 38 |
| 闭镲 | `c` | 42 |
| 开镲 | `d` | 46 |
| 高汤姆 | `A,` | 50 |
| 低汤姆 | `F,` | 47 |
| 吊镲 | `a` | 49 |
| 叮叮镲 | `g` | 53 |

**MIDI 表现力：**
- 鼓声部主要通过力度（velocity）变化实现动态。Orchestrator 可根据段落调整整体力度曲线，并在加花处提高力度峰值。
- 开镲与闭镲的切换可模拟踩镲动作，配合 CC4（踏板）实现。

## 键盘与合成器（适用于和声与铺底）

| Do | Don't | 原因与示例 |
|----|-------|------------|
| 和声层使用开放排列（`[FAc]` 跨八度） | 密集排列覆盖旋律区域（与旋律音区重叠） | 开放排列能留出空间给旋律，避免频谱拥挤。 |
| 长时值和弦配合 CC11 渐变 | 所有和弦都用相同力度和声像 | 动态变化能塑造乐句呼吸感。 |
| 钢琴声部可用踏板标记（`!ped!` 和 `!pedend!`） | 在快速和声变换处持续踏板 | 持续踏板会造成和声混浊。 |
| 合成器铺底（pad）可加合唱效果（通过 CC91 混响） | 所有声部使用相同声像（pan） | 声像分离能增强空间感。 |

**MIDI 表现力参考：**
| 技法 | 推荐 MIDI 事件 |
|------|----------------|
| 颤音 | CC1（调制）周期性变化，速率约 5–7 Hz |
| 力度渐变 | CC11（表情）平滑变化 |
| 滑音（glissando） | Pitch bend（起始 8192，终点值，再归零） |
| 踏板（钢琴） | CC64（延音），值≥64 踩下，<64 释放 |
| 弱音器 | CC71（滤波器）值 0–127 |
| 合唱/混响 | CC91（混响深度） |

## 如何使用本指南

- **Composer / Harmonist / Rhythmist**：在创作时，参考对应乐器组的 Do/Don't，避免不合理的写法；特殊效果（如故意重复同音制造机械感）可标注注释说明。
- **Orchestrator**：在生成 `expression_plan.json` 时，根据乐器组特性选择适合的 CC 事件（如弦乐长音加 CC1，木管断奏加短时 CC11 尖峰）。
- **Reviewer**：在评价乐谱时，可引用本指南指出反乐器写法，给出具体修改建议。

> 本指南是通用建议，并非绝对规则。若创作意图需要突破（如电子音乐中故意模拟非自然演奏），可注释说明“效果性写法”。
