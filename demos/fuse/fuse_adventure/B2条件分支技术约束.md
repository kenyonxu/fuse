## 更新：嵌套资源反序列化已修复（2026-08-10）

自 2026-08-10 后，preset 管道已支持 `BaseCondition` / `BaseInstruction` / `BaseEvent` 的递归序列化与反序列化（见 [addons/fuse/docs/system_docs/analysis/preset_nested_resource_flaw.md](../../../../addons/fuse/docs/system_docs/analysis/preset_nested_resource_flaw.md)）。

- **L2 可直接使用 `IfElse`**，条件与分支指令以内联 JSON 字典表达，无需 `res://...tscn::Resource_xxx` 指针。
- **L2/L4 均可使用复合条件** `CheckAll` / `CheckAny` / `CheckNot`，其子条件数组会正确还原为对象。
- **L4 `EventBinding.conditions`** 也自动支持嵌套复合条件。

### L2 IfElse 示例

```json
{
  "type": "IfElse",
  "condition": {
    "type": "CheckScopeVariable",
    "scope_source": 1,
    "custom_scope_id": "level_scope",
    "variable_name": "current_level",
    "comparison_operator": 0,
    "expected_value": 1
  },
  "true_instructions": [
    { "type": "ChangeScene", "scene_path": "res://demos/fuse/fuse_adventure/scenes/level_02.tscn" }
  ],
  "false_instructions": [
    { "type": "ChangeScene", "scene_path": "res://demos/fuse/fuse_adventure/scenes/level_01.tscn" }
  ]
}
```

## 决策建议

B2 现在有两种等价的实现路径：

| 路径 | 说明 | 适用场景 |
|------|------|----------|
| **L2 + IfElse**（推荐） | 一个 Trigger，内联 IfElse 按 `current_level` 分派 | 教学"条件分支"概念，结构紧凑 |
| **L4 + MultiEventTrigger** | 多个 EventBinding，每个带独立条件 | 教学"多事件绑定 + 条件分派"，事件与条件解耦 |

两者均可在纯 preset JSON 中完整表达，导入即用。

## 设计定案（2026-08-10 知惠 + 主人）

选 **L2 + IfElse** 落地，`presets/gameplay/next_level_button.json`：

```
OnButtonPressed(NextLevel)
└─ IfElse
   ├─ CheckScopeVariable(current_level == 1, level_scope)
   ├─ true  → ChangeScene(level_02)
   └─ false → ChangeScene(level_01)
```

- 两关场景 root 自带 `current_level`（bc6be8b），读哪个场景就是哪个值，循环天然成立
- 教学点：**同一事件按状态分派**（false 分支 = else 语义）
- B3（条件组合）见同目录 `B3条件组合技术约束.md`

> ⚠️ 字段名勘误（2026-08-10）：`CheckScopeVariable` 正确字段为 `comparison_operator` / `expected_value`（非 `operator` / `compare_value`）。反序列化对未知属性静默忽略，旧字段名会导致条件永远比较 null。示例已修正。
