## 发现的技术约束（已查源码确认）

1. **L2 的 IfElse 条件无法在 preset JSON 里构造**
   - `IfElse.condition` 是 BaseCondition 资源引用，现有 JSON（如 game_flow.json）里是
     `res://...tscn::Resource_xxx` 场景内嵌资源指针——AI 无法凭空生成，导入时也 load 不到
   - L2 的 Trigger 节点本身没有 conditions 字段（只有 event + action_runner + trigger_config）

2. **可行方案：B2 升级为 L4 MultiEventTrigger**
   - L4 的 EventBinding 原生支持 `conditions` 数组（`_deserialize_binding` 处理，条件可从 JSON 字典构造）
   - 结构：
     - binding 1: OnButtonPressed(NextLevel) + CheckScopeVariable(current_level == 1) → ChangeScene(level_02)
     - binding 2: OnButtonPressed(NextLevel) + CheckScopeVariable(current_level == 2) → ChangeScene(level_01)
   - 纯 JSON 可完整表达，导入即用，无需编辑器手动绑条件
   - 教学点升级：多事件绑定 + 条件分派（同一事件按状态走不同分支）
