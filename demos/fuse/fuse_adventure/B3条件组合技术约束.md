## 设计定案

### 1. player 域容器（生命）

- `player.tscn` 挂 `ScopeVariableContainer`，配置：
  - `scope_id = "player"`
  - `variables = { "life": 3 }`
- **生命周期语义**：player 是关卡运行时 Instantiate 的，`ChangeScene` 走 `change_scene_to_file` 整树替换 → player 随旧场景释放，容器 `_exit_tree` 自动注销 → **life 每关重置为 3**（主人已确认：三颗心制，每关重新开始）。
- 教学点：**「属于玩家的状态放 player 域」**——域的生命周期 = 容器节点生命周期。

### 3. 过关升级 preset（`presets/gameplay/level_end_check.json`）

- 挂载：`level_end_point.tscn`（替代/升级 B1 的 level_end_trigger 挂点）
- 结构（L2，IfElse 内嵌 CheckAll）：

```json
{
  "format_version": "2.0",
  "level": "L2",
  "display_name": "level_end_check",
  "category": "gameplay",
  "description": "终点旗：香蕉集齐 AND 生命>0 才过关，否则提示",

    "target_group": "player",
    "trigger_once_per_body": true
  },
  "action_runner": {
    "execution_mode": 0,
    "instructions": [
      {
        "type": "IfElse",
        "sequence_mode": 1,
        "condition": {
          "type": "CheckAll",
          "short_circuit": true,
          "conditions": [
            {
              "type": "CheckScopeVariable",
              "variable_name": "banana_count",
              "scope_source": 1,
              "custom_scope_id": "level_scope",
              "comparison_operator": 0,
              "expected_value": 3
            },
            {
              "type": "CheckScopeVariable",
              "variable_name": "life",
              "scope_source": 1,
              "custom_scope_id": "player",
              "comparison_operator": 2,
              "expected_value": 0
            }
          ]
        },
        "true_instructions": [

          { "type": "SetUIText", "ui_node_path": "CanvasLayer/UI_Collectables/HintLabel", "text": "还差香蕉！" }
```

- `comparison_operator`：0=Equals，2=Greater Than，3=Less Than（`life > 0` → operator 2，expected_value 0）
- `expected_value = 3`：关卡香蕉总数，落地时按场景内 `item_banana` 实例数核对

## 域设计（教学概念）

| 域 | 容器挂点 | 生命周期 | 变量 | 语义 |
|----|---------|---------|------|------|
| `player` | player.tscn | 随 player 实例（每关重建） | `life` | 属于玩家的状态（每关重置） |
| `level_scope` | 关卡场景根节点 | 随关卡场景（每关独立） | `current_level`、`banana_count` | 关卡内状态（进关重置） |

教学点：**变量放哪个域 = 它的生命周期归属**。跨场景要存的（如生命）放随玩家/全局的容器；关卡内的（如收集计数）放关卡容器。

## 字段名勘误（重要）

`CheckScopeVariable` 的正确导出属性名（以 `addons/fuse/preset_ai_context/fuse_component_schemas.json` 与 `check_scope_variable.gd` 为准）：

| 错误写法（B2 文档示例） | 正确写法 |
|------------------------|---------|
| `operator` | `comparison_operator` |
| `compare_value` | `expected_value` |

反序列化对未知属性静默忽略（`obj.set()` 失败不报错）——若沿用旧字段名，条件会比较 `expected_value = null`，永远不满足。**B2 文档示例需同步修正。**
