## 最终实现（level_end_point.tscn Trigger，主人手动）

```
OnArea2DEnter(../Area2D, player)
└─ GetNodesInGroup(player → grp_player)        # 本地
   └─ ArrayGet(grp_player[0] → player)
      └─ IfElse(condition: current_level == 1)   # level_scope
         ├─ true:  （空数组——直接放行到下方过关链）
         └─ false: RunConditionCheck(banana_count == 3)  # 不满足则中断（Stop）
            └─ ShowHideUI(ui_level_end)          # 过关链（无条件路径也走这里）
               └─ SetProcessMode(player → 禁用)
                  └─ SendEvent(LevelFinished)
```

**条件门模式**：IfElse 的 true 分支留空 = 「放行」；false 分支塞 RunConditionCheck = 「关卡 2 的闸门」。RunConditionCheck 默认语义 `on_condition_true=0`(Continue) / `on_condition_false=3`(Stop Execution)——只配 condition 即得「真继续 / 假中断」。

## 域设计（8/10 主人落地）

| 域 | 容器挂点 | 生命周期 | 变量 | 语义 |
|----|---------|---------|------|------|
| `player` | player.tscn `PlayerVariables` 节点（8/10 已加） | 随 player 实例（每关重建） | `life=3` | 属于玩家的状态（每关重置） |
| `level_scope` | 关卡场景根节点 | 随关卡场景（每关独立） | `current_level`、`banana_count` | 关卡内状态（进关重置） |

教学点：**变量放哪个域 = 它的生命周期归属**。

## 字段名勘误（沿用 8/10）

`CheckScopeVariable` 正确字段是 `comparison_operator` / `expected_value`（非 `operator` / `compare_value`）——反序列化对未知属性静默忽略，旧字段名会永远比较 null。
